# Формат config.json

Конфиг — это JSON по ключу в CMS (в прототипе — `content/config.json` или override из `cms.html`).
Все пути к ассетам — относительно `content/` (в нативе — относительно базового URL CDN).
В веб-прототипе `sound` и `effect.params.src` принимают только локальные пути внутри `content/`:
внешние URL, абсолютные пути, выход через `..`, шаблоны, query/hash и кодированные пути отвергаются.

```json
{
  "version": 1,
  "settings": { "globalCooldownMs": 3000, "maxParticles": 150, "sound": true, "haptics": true,
                "season": "auto", "albumAnchor": "avatar" },
  "prikoly": [ { …прикол… } ]
}
```

## settings

| Поле | По умолчанию | Смысл |
|---|---|---|
| `globalCooldownMs` | `3000` | неотрицательная пауза после полноэкранного эффекта (прикол с бо́льшим `priority` её не ждёт) |
| `maxParticles` | `150` | целый потолок частиц `0..500`; `0` отключает визуальные частицы, сохраняя звук и вибрацию |
| `sound`, `haptics` | `true` | глобально включить звук / вибрацию (у ребёнка ещё есть mute в альбоме) |
| `season` | `"auto"` | `auto` — по календарю; `autumn`/`winter`/`spring`/`summer` — «как будто сейчас середина сезона» для `dateRange` |
| `albumAnchor` | `"avatar"` | долгое нажатие на этот якорь открывает альбом находок |

## Прикол

| Поле | Тип | Смысл |
|---|---|---|
| `id` | строка, уникальная | ключ коллекции и лога |
| `title` | строка | название в альбоме и тосте «Новая находка» |
| `icon` | эмодзи | картинка в альбоме |
| `hint` | строка | подсказка в альбоме, пока не найдено (коротко, просто, без давления) |
| `enabled` | bool | выключенный прикол не создаёт триггер и не виден в альбоме |
| `priority` | число | при одновременном срабатывании играет больший; если ему не на чем играть (нет якоря, кармашки за краем) — следующий подходящий |
| `exclusive` | bool, `true` | `false` — прикол не соревнуется за приоритет и играет рядом с победителем (постоянная Капля, вехи поверх звезды) |
| `trigger` | объект | что запускает — см. ниже |
| `screens` | массив id \| `null` | где можно играть; `null` — на всех зелёных. Красная зона запрещена всегда |
| `schedule` | объект \| `null` | `{ "dateRange": "MM-DD..MM-DD", "timeOfDay": "HH:MM..HH:MM" }`, оба ежегодные/ежедневные, через Новый год и полночь можно |
| `cooldownMs` | число ≥ 0 | пауза между срабатываниями этого прикола. Эффекты `event`-триггеров (действия ребёнка) не ждут `globalCooldownMs` и мягко гасят предыдущий полноэкранный эффект того же или меньшего приоритета |
| `maxPerDay` | целое число ≥ 0 \| `null` | не чаще N раз в день (счётчик в `localStorage`) |
| `effect` | объект | `{ "type", "params" }` или `{ "variants": [ {type, params}, … ] }` — вариант выбирается случайно, это разнообразие, не награда |
| `haptic` | `light` \| `medium` \| `heavy` \| `success` \| `double` \| `null` | вибрация при старте (на iOS в вебе её нет — молча пропускается) |
| `sound` | путь \| `null` | например `"sounds/pop.wav"` |

В строковых параметрах эффекта `{поле}` подставляется из события: `"anchor": "task-{taskId}"`.

## Триггеры

| `type` | Параметры (по умолчанию) | Когда срабатывает |
|---|---|---|
| `event` | `name`, `where` | оболочка прислала событие, поля совпали с `where` |
| `shake` | `threshold` 14 (м/с²), `hits` 3, `windowMs` 1000, `debounceMs` 1500 | `hits` всплесков ускорения за `windowMs` |
| `tilt` | `rangeDeg` 20, `startThreshold` 0.12, `follow` 0.02 | непрерывно, пока телефон наклоняют: `{ x, y }` в −1..1 |
| `flip` | `holdMs` 300, `maxMs` 5000, `on` `"up"` | экраном вниз ≥ `holdMs` и обратно не позже `maxMs`; `on: "down"` — сразу, как лёг экраном вниз (эффект сам ждёт возвращения, см. `night`) |
| `still` | `seconds` 10, `threshold` 0.25, `rotationThreshold` 3 | лежит неподвижно `seconds` (один раз, пока не возьмут) |
| `multitap` | `anchor`, `count` 3, `withinMs` 450 | `count` быстрых тапов по якорю |
| `longpress` | `anchor`, `ms` 600 | долгое нажатие на якорь |
| `presence` | — | открыт зелёный экран (и сразу после сборки триггеров, например после сохранения в CMS). Для постоянных жильцов: идущий эффект получает `update({ screen })` |

### where (для `event`)

```json
{ "taskId": "dog_walk" }                          // равенство
{ "taskId": ["dishes", "clean_room"] }            // массив = одно из
{ "value": { "in": [777, 1111, 1234, 2222] } }    // одно из
{ "progress": { "gte": 0.5, "lt": 1 } }           // eq ne gt gte lt lte, можно несколько сразу
{ "progress": { "crosses": [0.25, 0.5, 0.75, 1] } } // порог пересечён: prevProgress < t ≤ progress
```

## Эффекты

### `particles` — частицы на canvas (полноэкранный)

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `mode` | `"normal"` | `"trail"` — следы цепочкой по траектории (лапки) |
| `spawn` | `"top"` | `top` (падают), `bottom` (всплывают), `center` / `anchor` (разлёт) |
| `anchor` | — | якорь для `spawn: "anchor"` и начала следов |
| `emoji` | — | эмодзи или символы (`"7"`, `"А"`); символы красятся из `colors` |
| `shapes` | — | `circle`, `rect` (конфетти), `star`, `spark`, `bubble`, `snow`, `petal`, `flake` и `crystal` (белые снежинки-кристаллы с мягкой тенью), `puff` (мягкий снежок) |
| `images` | — | картинки из `content/effects/` |
| `colors` | 5 цветов | для фигур и символов |
| `count` | 40 | целое `0..500`: частицы или шаги следа, не больше `settings.maxParticles` |
| `size` | `[18, 30]` | px, число или `[min, max]` |
| `speed`, `direction`, `spread` | от `spawn` | стартовая скорость px/с, направление в градусах (90 — вниз), разброс |
| `gravity`, `drag` | от `spawn` | ускорение px/с² (минус — вверх) и сопротивление; предельная скорость = gravity/drag |
| `wind`, `sway` | 0 | постоянный снос px/с и покачивание px |
| `rotation` | 0 | макс. вращение °/с |
| `flutter` | false | «переворачивание» в полёте (конфетти, лепестки) |
| `fade` | true | таять в конце жизни |
| `lifeMs` | `[2500, 4000]` | жизнь частицы |
| `emitMs` | 0 | выпускать частицы постепенно в течение `emitMs` |
| `durationMs` | 4000 | жёсткий предел: к этому моменту всё гаснет |
| `settleOn`, `settleChance`, `settleMs` | —, 0.5, 2000 | частица, долетевшая до верхнего края якоря, ложится на него и тает. Шаблон `"task-*"` — все видимые якоря с этим префиксом |
| `sweep` | true | лежащие частицы смахиваются пальцем (палец слушается пассивно, касание уходит в интерфейс) |
| `stepMs` | 160 | (trail) интервал между шагами |

### `lottie` — Lottie-анимация в точке

`src` (путь к JSON), `anchor` (иначе центр), `size` 160, `speed` 1, `durationMs`. Играет один раз и удаляется.
Те же файлы без изменений играют Lottie Android/iOS.

### `cssAnimate` — анимация самого якоря

`anchor`, `animation`: `flip` (сальто), `jump`, `wiggle`, `pop`; `durationMs`, `repeat`.

### `holo` — голографическая фольга (непрерывный, для `tilt`)

`anchor` (`card`), `intensity` 0..1, `fullAt` 0.45 (доля отклонения `tilt`, при которой перелив в полную силу:
при `rangeDeg: 20` это ≈ 9°), `sparkles` 14 (`0..40` искр), `chime` true (тихий перелив при первом «пойманном
блике», не чаще раза в 6 с), `idleMs` 900 (через сколько покоя гаснет), `durationMs` (предел жизни).
Четыре слоя со своим `mix-blend-mode`: радужные полосы (hard-light), бегущая полоса блика (screen), мягкий блик
(overlay) и искры (screen). Все слои повторяют прямоугольник и скругление якоря при прокрутке.

### `night` — «Кувырок»: ночь и рассвет (полноэкранный, для `flip` с `on: "down"`)

`stars` 46 (`0..120`), `maxNightMs` 20000 (если телефон так и не подняли — рассвет сам), `dawnMs` 2600,
`greeting` `"Доброе утро!"` (до 40 символов). Ночное небо со звёздами, луной и падающей звездой; когда телефон
снова лицом вверх — рассвет, солнце с лучами, приветствие, тихий утренний перелив и вибрация `success`.
Касаний не перехватывает, красная зона гасит сразу. Капля засыпает и потягивается по тем же датчикам.

### `sunbeams` — летние солнечные блики (полноэкранный)

`anchors` (`["card", "tabbar", "task-*", "moneybox-*", "feed-*"]`) — по каким карточкам пробегает тёплый блик
(до 8 видимых), `spots` 4 (`0..8` солнечных зайчиков по экрану), `durationMs` 4600. При reduced motion —
только мягкий тёплый свет без бегущих бликов и зайчиков.

### `coins` — звенящие копилки

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `anchors` | обязательный | непустой массив уникальных имён якорей копилок |
| `coinsPerCard` | `14` | целое `0..40`, число монет при полном прогрессе |
| `durationMs` | `2800` | неотрицательное время жизни, включая появление и затухание |

Триггер — `shake`, `screens: ["moneybox"]`, приоритет выше сезонных осадков. Число монет =
`ceil(progress * coinsPerCard)`, где `progress` — публичное `data-progress` якоря `0..1`. При нуле кармашек
не рисуется. Учитываются только видимые карточки и общий остаток `maxParticles`; малый бюджет распределяется
между карточками по кругу. При reduced motion монет меньше, они неподвижны, остаётся мягкое затухание.
Звон синтезируется локально и соблюдает общий mute; отдельный `sound` в записи не нужен.

### `resident` — Капля, сквозной персонаж

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `size` | `46` | размер `32..72` CSS px |
| `perches` | `{ "default": { "anchor": "tabbar", "x": 0.5, "y": "center" } }` | где живёт на каждом экране: `"<screen>"` или `"default"` → `{ anchor, x 0..1, y: top \| center \| bottom, plate }`. `plate: true` — белый «домик» на месте отдыха |
| `reactions` | см. ниже | событие → реакция; контент-менеджер меняет их в CMS («Реакции Капли») |
| `rangeDeg` | `15` | наклон для полного отклонения |
| `shakeThreshold` | `14` | порог тряски м/с² |
| `idleMs` | `20000` | через сколько без касаний срабатывает `idle` (`0` — никогда) |
| `stillMs` | `6000` | сколько телефон должен лежать неподвижно для `still` |
| `durationMs` | — | без него Капля постоянная; с ним — живёт столько и уходит (прежний режим, `anchor` → место на верхнем краю) |
| `anchor` | — | устаревшее: то же, что `perches.default = { anchor, y: "top" }` |

События в `reactions`: `tilt`, `shake`, `flip` (экраном вниз), `tap`, `swipe`, `still`, `idle` и любые события
шины (`task:done`, `tasks:allDone`, `moneybox:topup`, …). Реакции: `none`, `roll` (катится к краю, для `tilt`),
`joy`, `dance`, `giggle`, `dizzy`, `surprise`, `doze` (дремлет до первого касания/движения), `sleep` (спит, пока
телефон лицом вниз, потом потягивается), `leave` (уходит до следующего входа в приложение).

```json
"reactions": { "tilt": "roll", "shake": "dizzy", "flip": "sleep", "tap": "giggle", "swipe": "leave",
               "still": "doze", "idle": "doze", "task:done": "joy", "tasks:allDone": "dance", "moneybox:topup": "joy" }
```

В основном конфиге — `trigger: { "type": "presence" }`, `exclusive: false`, `screens: null`: Капля на всех
зелёных экранах, исчезает в красной зоне и возвращается на следующем зелёном. Это DOM/SVG, а не частицы: цикл
отрисовки идёт только во время движения, в покое дыхание и моргание делает CSS. Слой касаний не перехватывает,
кроме круга её тела: тап по Капле не нажимает вкладку под ней. Появление без звука; короткие тембры реакций
синтезируются локально и соблюдают mute. Капля резервирует одну единицу `maxParticles`; при `0` не появляется.
При reduced motion остаётся на месте и меняет выражение лица. Не тамагочи: ни голода, ни упрёков — только реакции.

## Примеры

**Новый прикол только конфигом** — «шарики по пополнению копилки на велосипед»:

```json
{
  "id": "bike-balloons", "title": "Шарики", "icon": "🎈", "hint": "Пополни копилку на велосипед",
  "enabled": true, "priority": 7,
  "trigger": { "type": "event", "name": "moneybox:topup", "where": { "moneyboxId": "bike" } },
  "screens": ["topup_success"], "schedule": null, "cooldownMs": 0, "maxPerDay": 5,
  "effect": { "type": "particles", "params": { "spawn": "bottom", "emoji": ["🎈"], "count": 14,
              "size": [30, 44], "sway": 20, "lifeMs": [2500, 3200], "durationMs": 3500 } },
  "haptic": "light", "sound": "sounds/pop.wav"
}
```

**Сезонный прикол** — только в декабре, по тряске, с оседанием на карте:

```json
"trigger": { "type": "shake" },
"schedule": { "dateRange": "12-01..12-31" },
"effect": { "type": "particles", "params": { "spawn": "top", "shapes": ["snow"], "settleOn": ["card"] } }
```

**Утреннее приветствие** — первый запуск за день до 11:00:

```json
"trigger": { "type": "event", "name": "app:firstOpenToday", "where": { "hour": { "lt": 11 } } },
"effect": { "type": "lottie", "params": { "src": "effects/sparkle.json", "anchor": "avatar" } }
```

## Проверка

- CMS (`cms.html` → вкладка JSON) проверяет конфиг теми же правилами, что и движок, и показывает,
  какие записи будут пропущены и почему.
- Проверяются не только типы, но и смысловые диапазоны: реальные даты/время, неотрицательные длительности
  и лимиты, диапазоны частиц, допустимые `spawn`/`shape`, параметры сенсоров и обязательные якоря/ассеты.
- `maxParticles: 0`, `count: 0` и `durationMs: 0` допустимы и действительно создают ноль визуальных частиц.
- В `index.html?debug=1` лог показывает каждое решение: `shake → season-winter-snow: ⏭ не сезон`.
- Вес `content/` целиком — не больше 6 МБ.
