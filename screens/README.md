# screens/

PNG экранов из Figma. Имена = id экранов из `app/screens.js`:

`home.png`, `tasks.png`, `tasks_done.png`, `moneybox.png`, `topup_success.png`, `content.png`, `transfer.png`
и (по желанию) `tabbar.png` — таббар отдельной картинкой.

- Экспорт @2x или @3x, ширина кадра 390 pt. Длинный экран — одной картинкой, оболочка его прокрутит.
- Таббар лучше экспортировать отдельно (`tabbar.png`), а сами экраны — без него: тогда он не уезжает при прокрутке.
- Положили файл — допишите его имя без `.png` в `READY_IMAGES` в `app/screens.js` (например `['home', 'tabbar']`).
  Пока имени там нет, оболочка рисует HTML-заглушку и не делает лишних запросов.
- После добавления PNG откалибруйте зоны: `index.html?debug=1` → «Калибровка» → протяните рамку по элементу →
  координаты `{ x, y, w, h }` в процентах окажутся в буфере обмена → вставьте в `zones` экрана в `app/screens.js`.
