# screens/

PNG экранов из Figma (кадр 375 pt, экспорт @2x). Имена = id экранов из `app/screens.js`:

`home.png`, `tasks.png`, `tasks_done.png`, `moneybox.png`, `moneybox_goal.png`, `topup_success.png`, `content.png`,
`transfer.png` и `tabbar.png` — закреплённый таббар (375×162 pt, с прозрачным градиентом сверху).

- Новая картинка → допишите её имя без `.png` в `READY_IMAGES` в `app/screens.js`. Пока имени там нет,
  оболочка рисует HTML-заглушку и не делает лишних запросов. Регистр в имени важен (GitHub Pages его различает).
- Нарисованные на экранах статус-бар (44 pt) и home indicator (34 pt) на телефоне срезаются, в рамке на
  десктопе — остаются. Нарисованный таббар (нижние 162 pt, `cropBottom`) срезается всегда — вместо него закреплённый.
- Если таббар на новом экране нарисован с другой активной вкладкой, её подставляют кусочком этого экрана
  (`TABBAR.active` в `app/screens.js`).
- Калибровка зон: `index.html?debug=1` → «Калибровка» → протяните рамку по элементу → `{ x, y, w, h }` в % от
  картинки окажется в буфере обмена → вставьте в `zones` экрана в `app/screens.js`.
