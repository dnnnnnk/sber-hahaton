# СберKids · Приколы

Хакатон Сбера «Создаём эмоции», трек «Приколы».

**Идея.** В приложении СберKids спрятаны маленькие живые сюрпризы: отметил прогулку с собакой — по экрану
пробежали лапки, тряхнул телефон осенью — посыпались листья и легли на карту, покачал телефон — карта
заиграла голограммой. Каждый эффект длится секунды, не мешает пользоваться приложением и никогда не
появляется на экранах с деньгами. Найденное собирается в альбом, а новые приколы и сезоны приходят из CMS без релиза.

## Демо

- Приложение: **https://dnnnnnk.github.io/sber-hahaton/** — откройте на телефоне.
- Режим разработчика: https://dnnnnnk.github.io/sber-hahaton/?debug=1 — кнопки «Тряхнуть», «Перевернуть»,
  наклон, лог решений движка, подсветка зон.
- CMS: https://dnnnnnk.github.io/sber-hahaton/cms.html — выключите прикол или смените сезон, нажмите
  «Сохранить»: приложение в соседней вкладке (и превью справа) поменяется без перезагрузки.

На iPhone при первом касании Safari спросит доступ к датчикам движения (или нажмите чип «✨ Включить волшебство»).

### Что найти

| Прикол | Как |
|---|---|
| 🐾 Лапки, 🫧 пузыри, 🔢 дождь из цифр, ✨ искорки, 📖 летящие буквы | отметить дело на вкладке «Дела» — у каждого дела свой эффект |
| 🎉 Праздник дел | отметить все дела |
| 🍂 Листопад / ❄️ снегопад / 🌸 лепестки / ☀️ солнечные зайчики | тряхнуть телефон (сезон по календарю или из CMS); частицы ложатся на карту и таббар либо разлетаются от центра |
| 💳 Голографическая карта | покачать телефон на главном |
| 🤸 Сальто | три быстрых тапа по аватару |
| ⭐ Звезда копилки | пополнить копилку (Lottie) |
| 🪙 Звенящие копилки | тряхнуть телефон в «Копилках»: монетки пересыпаются внутри карточек, их число зависит от прогресса |
| 💧 Капля на карте | два тапа по карте: наклон катит Каплю, тап смешит, тряска удивляет, свайп убирает |
| 📒 Альбом находок | долгое нажатие на аватар |

В конфиге есть и выключенные заготовки: «Красивое число» на балансе 777/1111, «Кувырок» (перевернуть телефон),
«Тихий час» (положить и не трогать), «Вехи копилки» (25/50/75/100 %). Включаются в CMS одной галочкой.

## Как устроено

```
app/      оболочка = существующие приложения: экраны из Figma, зоны, якоря → события в шину
engine/   движок = то, что пишем в нативе: триггеры → правила → эффект на прозрачном слое
content/  CMS-ключ + CDN: config.json, Lottie, звуки
```

- Новый прикол — это запись в `content/config.json` (+ ассет). Новый тип триггера или эффекта — модуль
  в `engine/triggers` или `engine/effects` и строка в реестре.
- Правила: красная зона (перевод, оплата, пополнение…) — эффект гаснет мгновенно; экраны, сезон и время,
  кулдауны, лимит в день, приоритеты. Каждое решение видно в `?debug=1`.
- Слой эффектов не перехватывает касания; один `requestAnimationFrame`, лимит частиц, DPR ≤ 2, пауза в фоне,
  `prefers-reduced-motion`. Движок грузится после первой отрисовки, ассеты — по требованию.
- Сторонние образы из черновых макетов закрыты нейтральными локальными слоями оболочки; вкладка «Контент»
  собрана собственной HTML-композицией без внешних картинок.
- Ни одного внешнего запроса, никаких данных наружу, никаких лотерей и стриков. Ассеты приколов ~0,2 МБ.

## Перенос в натив

Оверлей поверх приложения (Compose `Box` / SwiftUI `.overlay` с `allowsHitTesting(false)`), Lottie уже есть
в обоих приложениях, сенсоры — `SensorManager` / `CoreMotion`, конфиг — по существующему CMS-ключу.
Оценка — около 16–19 дней на платформу с P2, таблица соответствий в [docs/NATIVE.md](docs/NATIVE.md).

## Запуск локально

```bash
python3 -m http.server 8000
```

Затем http://localhost:8000/ , http://localhost:8000/?debug=1 и http://localhost:8000/cms.html.
Сборки нет — чистые HTML/CSS/JS-модули; единственная библиотека `lottie-web` лежит в `vendor/`.

## Показ P2 за минуту

1. На главном дважды коснуться карты. Капля появляется на её верхнем краю на 9 секунд.
2. Слегка наклонить телефон, коснуться Капли, встряхнуть, смахнуть. Касания и навигация продолжают работать.
3. Открыть «Копилки», прокрутить до карточек и встряхнуть. Сравнить число монет в карточках с разным прогрессом.
4. Пока монеты двигаются, открыть карточку или перейти к переводу: эффект прекращается, действие проходит.
5. В CMS выключить «Капля на карте» и «Звенящие копилки», сохранить: приложение подхватит настройки.

На компьютере: `?debug=1` → «Позвать Каплю» на главном / «Звенящие копилки» в копилках.
Кнопки соблюдают обычные проверки экрана и кулдаунов; для повторного показа есть «Сбросить кулдауны».
Переходы и отклик на нажатия включены в оболочке; системное уменьшение движения учитывается.

## Проверки P0 и P2

При запущенном локальном сервере и установленном **инструменте разработки** Playwright:

```bash
node tests/p0.assets.mjs
node tests/sound.lifecycle.mjs
node tests/p0.audit.mjs
node tests/p2.smoke.mjs
```

P0 проверяет все 8 экранов и зоны касания, все 15 включённых приколов и 22 визуальных варианта,
CMS/JSON/экспорт/горячее обновление, альбом и debug в обоих браузерах при 375×812.
Проверки ассетов и отмены звука запускаются обычным Node.js. Результаты и границы приёмки —
[docs/P0_QA.md](docs/P0_QA.md).

Приложению Playwright не нужен. Можно использовать уже установленный пакет через `PLAYWRIGHT_MODULE`
(абсолютный путь), сервер в подпапке через `APP_URL`, папку скриншотов через `QA_DIR`.
Прогон проверяет Chromium и WebKit при 375×812, CMS при 1280×900, жесты и уход с экрана, реальные клики
сквозь эффекты, красную зону, горячее выключение из CMS, общий лимит частиц, reduced motion, mute,
освобождение рендереров, отсутствие ошибок и внешних запросов. В Chromium измеряется отзывчивость при CPU ×4.
Чувствительность датчиков, звук, вибрацию и FPS на телефонах проверяют отдельно: [docs/DEVICE_QA.md](docs/DEVICE_QA.md).
